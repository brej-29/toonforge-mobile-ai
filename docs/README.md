# Documentation

This directory contains higher-level documentation for the **Mobile AI Cartoon Generation** project.

## Contents

- `architecture.md` – Detailed architecture overview and component interactions.
- `model_pipeline.md` – Model download, inference, conversion/quantization, and benchmarking pipeline.
- `deployment_hf.md` – How to deploy Gradio, FastAPI, and Streamlit components to Hugging Face Spaces (CPU-first, optional ZeroGPU).
- `mobile_build.md` – How to build and distribute the Flutter mobile app (including store fees and free distribution options).
- `api_contract.md` – HTTP API contract for the FastAPI backend (endpoints, request/response shapes, examples).

Additional documents that may be added later:

- User-facing guides (web, mobile).
- Developer onboarding and style guides.
- Performance, scaling, and observability notes.

See also the `context/` directory, which acts as a living specification for goals, decisions, and change history.
